Uni-Bean 豆有所應：你有需要，豆有回應！

結合 BM25 關鍵字檢索 與 Ollama 本地端大型語言模型 (LLM) 之輕量化校務 RAG 問答系統。免除昂貴商業 API 費用與傳統 XAMPP 笨重環境，打造具備「原始文件來源標註」的跨裝置 PWA 校園服務。

RWD 響應式網頁設計 ＋ PWA 跨裝置自動調適規格表

你可以直接縮放瀏覽器視窗寬度，或用手機掃描 QR Code 驗證以下介面轉換行為

設計項目 手機版 (`<= 1024px`) 電腦網頁版 (`> 1024px`)
頁面配置 單欄式（直式聊天介面、底部固定輸入框） 雙欄或三欄（左選單、中對話、右來源）
功能選單 頂部漢堡選單（點擊滑出可收合抽屜） 左側固定導覽列（常駐顯示）
AI 問答 全螢幕聊天區 中央主要聊天面板
文件來源 點擊來源標籤由底部展開抽屜 (Bottom Sheet) 右側常駐顯示「檢索文件參考來源」側欄
校園地圖 手機全螢幕地圖＋底部資訊卡 左地圖與右處室建築資訊並排顯示
語音輸入 支援行動裝置麥克風可用時提供 支援瀏覽器 Web Speech API 可用時提供
使用方式 掃描 QR Code 開啟並支援加入主畫面 (PWA) 瀏覽器輸入網址直接開啟

前端與 PWA

HTML5、CSS3 (Tailwind)、JavaScript、RWD 響應式布局、Web Speech 語音辨識、PWA 離線快取與桌面安裝。

後端 API 服務

Python + FastAPI 高效能非同步架構，自動產生 Swagger API 文件，完全免安裝笨重的 XAMPP 環境。

RAG 檢索增強生成

結合 BM25 檢索相關文件段落，再由本地 Ollama 運行開源 LLM 統整回答，不需購買 OpenAI API。

SQLite 輕量資料庫

SQLite 目前保存已匯入的校務文件與段落，學年度與文件有效性需由管理者核實。

FastAPI + Ollama 後端 API 端點設定（供第二階段串接使用）

本網站使用 FastAPI + SQLite BM25 檢索；離線未連線時僅提供介面預覽，不會產生假校務答案。
